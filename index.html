  1. Both of you install this app and open it.
  2. Agree on one secret key (in person or by phone call). Enter it in the Key tab on both phones and tap Save.
  3. To send a message: Scramble tab → type → Scramble → copy/share the scrambled text.
  4. On the other phone: Descramble tab → paste → Descramble.
The key never leaves your device. Encryption happens locally with AES-256-GCM. If you lose the key, messages cannot be recovered.
